## TROUBLESHOOTING QUICK REFERENCE

**File won't paste into GitHub?**
- File too large? Split it.
- Syntax error? Check HTML — might be missing closing tag.
- GitHub glitching? Try different browser (Safari on iPad).

**Doc pages not showing up?**
- Check file is in `/docs/` folder (path: `docs/faq.html`)
- Check nav paths are correct (`../index.html` from docs)
- Check CSS path is `../css/styles.css` from docs pages

**Site looks broken after upload?**
- Hard refresh: Swipe down on Safari refresh bar
- Check dev tools (Safari → Develop → Console) for errors
- Make sure `css/styles.css` exists and path is correct

**Live site shows 404?**
- Make sure you have `index.html` in root (not in subfolder)
- Make sure GitHub Pages is enabled (Settings → Pages)
- Wait full 5 minutes for rebuild
